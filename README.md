# 记账本 - Web 应用

纯 Web 应用，浏览器打开即用，支持 CSV / Excel / PDF 账单导入，自动去重，多账户管理，余额对账。

## 在线使用

部署到 GitHub Pages 后，直接通过链接访问：
`https://<用户名>.github.io/bookkeeping/`

## 功能

- **流水管理**：查看所有交易，按账户筛选，给每笔交易选择消费分类
- **统计分析**：按日/周/月/年查看消费，分类支出占比，账户收支拆分
- **账户管理**：储蓄卡、信用卡、现金等多账户，信用卡余额可为负（=欠款）
- **余额对账**：应有余额 vs 实际余额，差额不为 0 提示漏记
- **账单导入**：
  - CSV（银行导出）
  - Excel .xlsx/.xls（建行导出的"假CSV"也能识别）
  - PDF（招行信用卡账单）
  - 银行智能识别：招行/工行/建行/农行/中行
  - 指纹去重：同一笔交易不会重复入库
- **转账**：信用卡还款 = 内部转账，不计入消费

## 本地使用

直接用浏览器打开 `index.html` 即可。数据存储在浏览器 localStorage 中。

## 技术栈

- 纯 HTML/CSS/JavaScript（无框架、无构建工具）
- xlsx 库（CDN）：Excel 文件解析
- pdf.js（CDN）：PDF 文件解析
- localStorage：数据持久化
